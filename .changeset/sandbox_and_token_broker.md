# Games now run sandboxed and never see your Minecraft token

Every instance runs in a sandbox that can only see its own folder, so a malicious mod can no longer read your browser passwords, Discord, wallets or other launchers. The game gets a stand-in token: OneClient answers its account requests itself and blocks any attempt to rename your account or change its skin. You can turn the sandbox off per instance in its Security settings.
